# WebSite-MohamedPlombier

Site internet statique moderne pour un artisan plombier indépendant basé à Dijon, pensé pour la conversion locale et le SEO.

## Pages incluses

- `index.html` : page d'accueil optimisée SEO local
- `services.html` : détail des prestations
- `zones.html` : zones d'intervention autour de Dijon
- `contact.html` : informations de contact et bloc devis
- `portfolio/index.html` : index portfolio
- `portfolio/chantiers/renovation-cuisine-dijon.html` : exemple de page chantier statique

## SEO intégré

- Meta title/description par page
- Balises Open Graph sur la page d'accueil
- Données structurées `Plumber` (JSON-LD)
- `robots.txt` et `sitemap.xml`
- Liens internes et structure de navigation claire

## Ajouter un nouveau chantier portfolio

1. Dupliquer un fichier dans `portfolio/chantiers/`.
2. Mettre à jour le titre, la méta description et les contenus.
3. Ajouter vos photos (dans un futur dossier `assets/images/portfolio/`) et remplacer les placeholders.
4. Ajouter le lien sur `portfolio/index.html`.


## Positionnement éditorial

- Ton orienté artisan indépendant (interlocuteur unique)
- Mise en avant de la qualité de service et des finitions
- Bloc dédié à la dernière réalisation sur la page d'accueil
